# S3 模块 C：可运行指标候选（非最终公式）

> **DECISION** 本文件提供透明、可计算的第一版候选及反例。未确定最终 AIV、权重、DHI 目标分布、跨群体校准或阈值。候选分数只针对可观察交互表现证据，不能解释为因果增量/稳定能力。

## 共同数据约定

- $z_i\in\{1,...,6\}$ 是有效的 `student_evidence_bloom` 标签。U 不纳入等级分母，覆盖率另报。
- 若使用概率标签 (p_{ik})，线性指标直接使用类别概率期望；非线性 CTQ/DHI 采用多重标签抽样传播不确定性。
- 学生聚合先限定 cohort、去除/标记 AI 与 System turns，报告有效 student turns / sessions / transitions 数。
- 正常例、极端例和可刷分反例均为数学演示输入，不代表附件中已观察到该行为。

## C1. ABL 候选：平均可见 Bloom 层级

\[
ABL_s=\frac{\sum_{i\in s}z_i}{n_s},\quad n_s>0;
\qquad ABL_s^{prob}=\frac{1}{n_s}\sum_i\sum_{k=1}^6kp_{ik}.
\]

| 属性 | 候选性质 |
|---|---|
| 定义域/有界性 | $ABL\in[1,6]$；供 AIV 使用时映射 (x_{ABL}=(ABL-1)/5\in[0,1])。若 (n_s=0) 则 NA。 |
| 单调性 | 固定其余 labels 和分母，任一标签升高会使 ABL 不降。 |
| 轮次/样本量敏感性 | 这是 turn-weighted 均值；长对话权重更大。增加同层 turns 对均值的效果依已有均值而定，增加更高层 turn 会抬高 ABL。样本量不改目标定义，却影响方差/区间。 |
| 正常例 | 标签 ((2,3,4,5))，ABL=3.5。 |
| 极端例 | 所有 turns 都是 L6，则 ABL=6；不能据此断言实际能力达到最高。 |
| 可刷分反例 | 在原来两个 L2 turns 之后重复加入大量“请设计创新模型”等 task prompts，并误把 task 层次计入 student evidence；错误口径会把 ABL 人为推高。防护：分离 task/evidence、学生文本证据、重复去重敏感性。 |

## C2. HOT% 候选：高阶学生证据占比

\[
HOT_s=\frac{N_{4,s}+N_{5,s}+N_{6,s}}{n_s}
=\frac{1}{n_s}\sum_{i\in s}(p_{i4}+p_{i5}+p_{i6}).
\]

| 属性 | 候选性质 |
|---|---|
| 定义域/有界性 | $HOT\in[0,1]$；百分比展示为 (100HOT\%)。 (n_s=0) 为 NA。 |
| 单调性 | 固定分母，将低/中阶真实证据标签改为高阶时不下降；turn 集合变化时无全局单调保证。 |
| 轮次/样本量敏感性 | turn 比例，不因同类复制必然变化，但少样本方差大；大量高阶重复/路径提示可抬升。 |
| 正常例 | ((L1,L3,L4,L5)) 得 (HOT=2/4=0.5)。 |
| 极端例 | 全部 L1–L3 得 0；全部 L4–L6 得 1。 |
| 可刷分反例 | 学生只写“评价一下、分析一下、创造一个”，没有标准、证据或方案，却按触发词全标高阶。防护：行为定义 codebook；盲标；关键词对抗测试。 |

## C3. CTQ 候选：净认知跃迁方向

针对同一 session 内相邻、有效、学生 evidence labels，定义 (d_t=z_{t+1}-z_t)：

\[
CTQ_{sess}=\begin{cases}
0.5,&\sum_{t=1}^{J-1}|d_t|=0,\\
\frac12\left(1+\frac{\sum_{t=1}^{J-1}d_t}{\sum_{t=1}^{J-1}|d_t|}\right),&\text{otherwise}.
\end{cases}
\]

学生级候选为有效 session 等权平均 $CTQ_s=S_s^{-1}\sum_qCTQ_{sq}$，同时报告有效 session 数和 transition 数。

| 属性 | 候选性质 |
|---|---|
| 定义域/有界性 | 净位移绝对值不超过总变差，所以 $CTQ\in[0,1]$。无层级变化为可解释基准 .5；纯上升=1，纯下降=0。 |
| 单调性 | 方向性而非逐标签坐标单调：总体净向上时在 .5 以上，净向下时低于 .5；提高一个中间标签可能改变前后两个 transition，故不保证 CTQ 一定上升。 |
| 轮次/样本量敏感性 | 比值抵消重复相同幅度的单向跃迁的数值规模，且拆分单调跃迁为若干小步时净位移/总变差不变。短 session 极不稳定；分母为零按基准值处理。 |
| 正常例 | ((L2,L4,L3))：差分 (+2,-1)，CTQ=(0.5(1+1/3)=0.667)。 |
| 极端例 | ((L6,L4,L2)) 纯下降，CTQ=0；((L1,L3,L6)) 纯上升，CTQ=1。 |
| 可刷分反例 | Agent 逐轮诱导学生复述 L1、解释 L2、应用 L3、分析 L4、评价 L5、设计 L6，即使学生只是照模板短答，路径也可获得 CTQ=1。防护：分别保存 task path 与 student evidence；检验答案充分性/独立性；用 AI 回答移除与反例攻击。 |

**局限（ASSUMPTION）**：此简洁候选只测净方向与单调一致性，不是跃迁的教育质量；任何纯上升路径都接近 1，不区分幅度/正确性。后续若增加质量权重须提出独立证据和新的公理检查，不在此阶段改成复杂模型。

## C4. DHI 候选：分布相对目标的总变差健康度

先将 student evidence 折叠成低/中/高分布 $p=(p_L,p_M,p_H)$，并由明确教学目标指定 $p^*=(p_L^*,p_M^*,p_H^*)$。

\[
DHI(p;p^*)=1-\frac12\sum_{r\in\{L,M,H\}}|p_r-p_r^*|.
\]

| 属性 | 候选性质 |
|---|---|
| 定义域/有界性 | $p,p^*$ 都在概率单纯形，故 $DHI\in[0,1]$；在 $p=p^*$ 取 1，距离越远值越低。 |
| 单调性 | 对总变差距离径向单调（离 $p^*$ 更远则 DHI 不增）；不是每个类别逐坐标的“越多越好”指标。 |
| 轮次/样本量敏感性 | 对比例分布而非总 turns 定义，复制同分布所有记录不改理论分数；小样本经验分布仍噪声大。 |
| 正常例 | 对称候选目标 (p^*=(1/3,1/3,1/3))，观测 (p=(0.6,0.3,0.1))，DHI=(1-0.5(0.267+0.033+0.233)=0.733)。 |
| 极端例 | 同一对称目标下，全为高阶 (p=(0,0,1))，DHI=(1-2/3=0.333)。它低是因为偏离“均衡”目标，不代表学生表现差。 |
| 可刷分反例 | 学生以低质量的简单短语覆盖低/中/高类别，恰好凑成目标比例，DHI=1。防护：不得把“健康分布”解释为掌握；结合证据质量、coverage、反操纵样例并披露 p* 来源。 |

**对称/非对称候选**：对称示例 (p^*=(1/3,1/3,1/3)) 只是数学演示，不宣称教育理想；非对称形式使用 ((a,b,1-a-b))，由课程学习目标/专家共识/实证设计明确其来源。不能用本届样本自身的平均分布作“理想分布”后再评价本届学生。p* 当前 UNKNOWN。

## C5. MAB 候选：饱和的多智能体广度

设 (m_s) 为学生在合格 session 中至少出现一次可核实、有效的学生互动的去重 agent type 数；(K) 是固定且公开的可用 agent catalog 大小。

\[
MAB_s=\frac{\min(m_s,K)}{K},\quad K>0.
\]

| 属性 | 候选性质 |
|---|---|
| 定义域/有界性 | $m_s\in\{0,...\}$，$MAB\in[0,1]$，达到 K 后饱和。 |
| 单调性 | 新增一个有效且不同的已核实 agent 前不下降；达到 K 后不再增加。 |
| 轮次/样本量敏感性 | 去重后，同一 agent 增加调用次数不增加 MAB；样本越多越容易观察到新 agent，故有暴露机会差异。跨学期 agent catalog 变化会破坏可比。 |
| 正常例 | 固定 (K=4)，有两种可核实 agent 互动，MAB=0.5。 |
| 极端例 | 已观察 $m_s\ge4$，MAB=1；只表示广度达到 catalog 上限，不表示有效学习。 |
| 可刷分反例 | 为每个智能体发一个空泛/重复问题便获得完整广度分。防护：只计符合定义的有效互动、去重、虚增 agent 攻击；但即便如此 MAB 仍是工具使用广度，需低权重/单列解释。 |

**UNKNOWN**：跨学期共同 catalog 与春季每条对话的 agent 身份尚未充分核实；这两项确认之前，MAB 不用于秋春比较。

## C6. AIV baseline 候选（仅透明基线）

归一化 (x_{ABL}=(ABL-1)/5)，其余 (x_{HOT}=HOT)、(x_{CTQ}=CTQ)、(x_{DHI}=DHI)、(x_{MAB}=MAB)。等权 baseline：

\[
AIV^{base}_s=\frac15(x_{ABL,s}+x_{HOT,s}+x_{CTQ,s}+x_{DHI,s}+x_{MAB,s}).
\]

一般透明候选族为 $AIV_s(\mathbf{w})=\sum_jw_jx_{js},\;w_j\ge0,\;\sum_jw_j=1$。本阶段只要求可比较，不选择“最优”权重；等权也是价值判断基线，不是客观真值。`feedback` 保持独立，不默认进入 AIV。所有 component 均需满足来源可用/解释条件；不可用组件不能静默填零。输出 AIV 同时附区间/`AIV_uncertainty` 和 rank stability。

| 属性 | 候选性质 |
|---|---|
| 定义域/有界性 | 若五个 component 在 [0,1] 且权重非负、和为 1，则 $AIV\in[0,1]$。 |
| 单调性 | 对任一组件单调非减；相互补偿由加权算术平均引入，是否允许是待决策的教育价值假设。 |
| 轮次/样本量敏感性 | 继承 ABL/HOT/CTQ/DHI/MAB 的样本和选择敏感性；增加噪声 turns 可能改均值与排名。区间随有效样本量反映部分不确定性。 |
| 正常例 | 合成组件 ((0.50,0.50,0.667,0.733,0.50))，等权 AIV≈0.580。仅数学演示。 |
| 极端例 | 五项均为 1 则 AIV=1；这不证明长期掌握，因为指标仍来自交互表现。 |
| 可刷分反例 | 高阶关键词/重复问题可同时推高 ABL/HOT/CTQ；空泛地触达多个 agent 推高 MAB，线性合成仍增分。此例表明构造属性不能自动抗操纵。 |

## 候选适用边界

1. ABL、HOT、CTQ、DHI、MAB 表示不同统计对象；它们高度相关或存在机械构造联系时不能把总分当作五个独立证据。
2. DHI 需人工批准理想分布及其来源；MAB 需核实 agent catalog；两者未满足前 AIV baseline 仅可用合成示例，不应用于学生数据排名。
3. 对短文本/稀疏学生，采用区间/NA/coverage 标签，不强行排出完整榜单。
4. 任何最终方案都要检查权重 ±10%、标签概率、重复/关键词/AI 文本攻击、agent removal 与跨学期可比性。
