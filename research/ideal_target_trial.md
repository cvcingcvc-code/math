# S3 模块 B：理想目标试验与现有数据映射

> **DECISION** 先定义理想目标试验，再看现有日志能识别到哪一级。题目中提及 PSM/DID 不构成使用这些方法的理由。当前不估计 AI 因果效应。

## 1. Ideal Target Trial 协议

| 要素 | 理想设计 | 状态/需要说明 |
|---|---|---|
| **Population** | 指定学期、指定数学建模课程中满足注册/参与资格的学生；入组前确定 cohort、课程内容和基线测量。 | ASSUMPTION：目标是该课程学生；人群边界须用官方 roster 确认。 |
| **Treatment** | 一个预先定义的 AI 辅助策略，例如有学习护栏的探知侠/指定脚手架路径；固定 agent 版本、可用功能、剂量/时间窗口、教师指导与学习任务。若比较多个 agent path，应设为多个明确处理臂。 | DECISION：处理不能笼统写“用了 AI”。不同智能体与引导流程是不同 treatment。 |
| **Comparator** | 相同课程内容、任务、时间和教师支持，但无 AI 辅助（或常规教学/延迟获得 AI）；与 treatment 在同一可比窗口实施。 | UNKNOWN：现有附件未发现明确无 AI comparator。跨学期不自动等于处理/对照。 |
| **Assignment** | 理想为学生/班级随机分配 treatment/comparator，按班级聚类时预先处理 cluster assignment 与推断。 | ASSUMPTION：随机试验可增强可识别性，实际干预需课程/竞赛许可。 |
| **Time zero** | eligibility 确认、基线测试完成、分配 treatment 的同一天/同一学习单元开始前。 | DECISION：不能用第一次成功交互定义入组后再回溯处理而制造不死时间/选择偏差。 |
| **Outcome** | 主要 outcome：统一、盲评、无 AI 条件下的课程相关学习表现（经共同 rubric 计分的标准化独立任务/测验）；次要 outcome：延迟保持、迁移、AI 辅助即时任务表现、学生感知。 | UNKNOWN：现有附件中是否存在统一独立成绩/测试字段待核；日志认知标签不是独立 outcome。 |
| **Follow-up** | 干预后共同时间点独立后测；若可行，数周后延迟保持/迁移测验。 | ASSUMPTION：随访窗口待教学日历和可行性确定。 |
| **Estimand** | 主要为 ITT：在目标 eligible 人群中，分配到策略 (a) 相对 comparator (0) 对独立 outcome 的平均因果效应：$ATE=E[Y^{a}-Y^{0}\mid eligible]$。多臂时估计 (ATE_{a,b})。 | DECISION：先定义分配策略的效果；按依从/实际使用的 per-protocol effect 为次要 estimand，需更强假设。 |
| **Confounders / baseline covariates** | treatment 非随机时至少考虑基线数学/数模知识、既往学业表现、专业/年级、AI 素养/既往 AI 使用、学习动机/投入、课程班级/教师/时间、任务难度、数字资源可及性，以及基线 outcome。仅用 treatment 前变量。 | 多数在当前日志未见，标 UNKNOWN；不能以治疗后互动深度作为普通基线混杂控制变量。 |
| **Adherence/contamination** | 记录实际是否使用、剂量、跨臂工具使用、教师/同伴支持、AI 版本与提示策略。 | UNKNOWN：现有导出覆盖完整度和控制实验室外 AI 使用的能力未知。 |
| **Analysis** | 随机试验按分配进行组间对比并考虑聚类；观察性 emulation 只有在处理/对照、time zero、结果和处理前混杂可测时，才考虑调整/加权，并报告重叠、平衡、敏感性。 | DECISION：模型选型服从 estimand 和识别条件，不反向用复杂方法替代设计。 |

## 3. 当前可报告的证据阶梯

| 等级 | 定义 | 当前可用性 | 可接受表述 |
|---|---|---|---|
| **Level 1：描述性差异** | 对清洗后可确认的日志 cohort 报告频次、可见文本标签、session 特征、反馈、缺失和覆盖率。 | **当前最高支持等级。** 需完成 cohort/speaker/label 校验。 | “该导出/可判读学生互动中观察到……；描述性差异不解释为 AI 导致。” |
| **Level 2：条件关联** | 在可用观测协变量下建模 agent/path 与互动表现的条件关联，明确非随机使用、自选择及遗漏混杂。 | 若行级班级/课程/时间/基础变量和 agent path 可以核实，可能支持探索性 Level 2；当前字段充分性 UNKNOWN，不能先声称已控制关键混杂。 | “控制所列可观测协变量后的关联；仍可能受未测混杂和测量误差影响。” |
| **Level 3：满足识别条件的准因果估计** | 预先明确 estimand/对照/时间零点/结果，处理分配和观测设计支持条件可交换性、重叠、平行趋势等识别假设，另做敏感性诊断。 | **当前不支持。** 无明确无 AI comparator、共同独立前后测与分配机制信息；秋春差不构成 DID。 | 只有补齐设计和字段并论证假设后才能使用“准因果/因果估计”。 |

## 4. 为什么当前不强行做 PSM / DID

- **PSM**：匹配需要 treatment 和 comparator 定义、处理前混杂变量、共同支持/重叠及合理的无未测混杂假设。当前不可见无 AI 组与基线能力/动机等关键变量；算出 propensity score 不会补出这些信息。
- **DID**：需要相应处理组和对照组在处理前后有共同可比 outcome、处理时间及平行趋势依据。只有秋季/春季两批不等同 DID：学生构成、课程、agent、日志/测量字段均可能变化，且未核到共同独立 outcome。
- **Negative controls / placebo**：可发现部分模型偏差，但需要理论上没有因果路径的合理对照变量；当前可用变量是否满足条件 UNKNOWN，不能预造负对照。

## 5. 使 Level 3 变得可行所需字段/设计

1. 官方 roster、班级/课程/教师、课程/测验版本和完整日期窗口；学生脱敏稳定 ID。
2. 分配方式、AI 可用性/策略、工具版本、首次分配时间、实际使用/污染/跨工具暴露和依从记录。
3. 处理前基线学习成绩/知识、专业/年级、AI 素养/既往使用、动机/资源等关键混杂变量。
4. 两组共同的无 AI 盲评后测，理想地加上延迟保持/迁移；题目难度和评分 rubric 统一或可等值链接。
5. 预先登记目标 population、treatment、comparator、time zero、outcome、follow-up、estimand、排除/失访和统计分析计划。

**阶段结论（DECISION）**：现在主结果只做 Level 1；数据允许时补充 Level 2 条件关联并逐项声明控制变量。未满足前述设计和字段之前，不做/不报告 Level 3。
