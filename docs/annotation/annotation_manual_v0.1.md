# 认知证据标注规则手册 V0.1

版本：V0.1｜用途：pilot annotation｜状态：待真实 pilot 校准，非已验证量表。

## 0. 范围与依据

研究方向沿用会话冻结表述：《考虑智能体引导偏差与标注不确定性的教育 AI 增量价值评价》。研究对象是学生在 AI 辅助学习中的可观察交互与学习表现证据，不是 AI 回答质量或长期稳定能力。本次未取得独立的 S3 文件，不推断额外的 S3 决策。

依据为 `03_evidence_matrix.md`、本会话文献综述 V1 与上述冻结方向，不新增文献。矩阵 A1/A2（摘要级）支持分类语义及情境歧义；A4/A5/A7、B2/B4（全文阅读）支持测量边界和辅助表现与学习的区分；A3（全文阅读）支持提示可塑造任务层次；F1/F2（摘要级）支持一致性校验。撤稿条目 B7 不作为依据。以下具体阈值、编码约定和人工案例是本项目的操作规则，不冒充文献已验证的标准。

核心约束：任务要求不等于学生证据；角色不等于内容作者；等级不等于正确性；缺证据不等于低能力；提示顺序不等于学生发展顺序。本文不定义 AIV 公式，不清洗真实数据，不执行标注。

## 一、分析单位与准入

### 1. Turn

Turn 是一次可辨认发送行为所产生的完整消息，具有单一发送角色。平台一个单元格若混合学生问题和 AI 回答，不能整体作为学生 Turn；可明确分离时生成派生记录并保留原始行号、角色边界和文本位置，无法分离则标 Unknown。不得按一句话或一个关键词随意增加 Turn 数。

同一 Turn 内有多个独立任务或论证时，可建立 `parent_turn_id` 下的分段记录（如 `r001#s01`），各段单独双轴编码；分段不是新的发送次数。不可分的综合任务，以完成任务不可缺少的认知操作判 Task；Student 以明确展示的最高可支持操作判级，并在 reason 指出完整证据片段，不能因一句高阶动词取最高级。分段方式与最高可支持规则均须在 pilot 检验。

### 2. Session

Session 是同一学生围绕可追溯任务进行的连续对话容器。优先使用原平台会话 ID；另行记录任务和智能体切换，不据此擅自断开原会话。没有会话 ID 时，只能依据同一任务、连续轮次和时间关系建立临时 session，并记录边界不确定。V0.1 不设任意分钟阈值；无法恢复连续性时使用 singleton/unknown，不拼接不相关消息。

Session 提供语境，不将 AI 先前答案转移为学生证据，不将学生后续高阶表现回填到先前 Turn。应为两名标注者提供相同的必要前文，记录 context_record_ids；后文仅用于另行澄清来源/边界，并保留原判，不回溯增加先前证据。

### 3. Student

Student 是稳定脱敏标识对应的个体分析单位，不以姓名猜测合并。身份匹配不明时保留未匹配状态；可继续文本编码，但不能据此做学生级关联。Student 包含多个 Session/Turn，本手册不规定学生总等级，不取最高 Turn 代表能力。

### 4. Turn 何时可以进入 Bloom 分析

所有记录均可进入人工审计表，但两轴准入分别判断：

1. 正文可读、边界可定位、上下文足以识别认知操作，才可赋相应轴 L1–L6。
2. Task 可对明确任务编码，即使任务由 AI 提出或学生委托 AI 执行；必须注明任务执行对象。AI 内容仅进入任务/上下文审计，不进入学生证据统计。
3. Student 轴只有在 Student 角色下，存在可归属于该学生的可见认知证据时才赋 L1–L6。由提示触发不自动排除；直接搬运已给出的认知内容不得计入。
4. 角色或内容来源无法确定、链接无正文、上下文缺失影响判断时，相关轴为 UNDETERMINED。不可用 L1 填补缺失。
5. 明确没有展示认知操作时，Student 轴为 NO_EVIDENCE；它是“本条未显示”的状态，不是零能力。

## 二、主体归属与内容来源

`speaker_role` 固定为 Student / AI / System / Unknown：

| 角色 | 判定依据 | 处理 |
|---|---|---|
| Student | 可信学生发送字段或明确对话边界 | 判断内容来源后编码 Student 轴 |
| AI | 可信助手字段或明确 AI 回答边界 | Student 轴 NOT_APPLICABLE；可保留 Task 轴 |
| System | 平台通知、系统提示、工具状态等明确系统记录 | Student 轴 NOT_APPLICABLE；只有明确教育任务才编码 Task |
| Unknown | 边界混合、字段冲突或角色证据不足 | Student 轴 UNDETERMINED，进入复核 |

不能凭语气、文本长度、“像 AI”或模型检测器单独定角色。学生发送 AI 原文时，speaker_role 仍为 Student；在 reason/扩展字段记录 copied_ai，不伪改角色。

### 来源处理规则

- **AI 生成内容**：只作为任务暴露或语境；不能成为学生证据。
- **学生复制 AI 内容**：若前文可核实逐字或语义实质照搬，无学生新增操作，Student=NO_EVIDENCE；若仅怀疑，Student=UNDETERMINED，不能武断断言复制。
- **学生纯粘贴题目/资料**：题目可用于 Task；被粘贴的知识内容不视为学生展示。没有额外作答时 Student=NO_EVIDENCE；粘贴来源与本人贡献均不明时 UNDETERMINED。
- **简单确认**：“对”“明白了”“继续”“很好”不展示理解或评价，Student=NO_EVIDENCE。自称理解不等于显示理解。
- **重新组织 AI 内容**：仅换词、调序、排版不充分；若在可追溯前文基础上加入自己的解释、例子、步骤、关系或标准，只对新增操作编码。无法分离新增与供给内容时 UNDETERMINED。
- **学生独立增添内容**：这里的“学生来源”仅指现有记录未显示外部供给且内容可归于学生，不保证现实中完全无辅助。保留 assisted/context 标记，不称为无 AI 独立能力。

## 三、双轴编码与非等级状态

### Task Bloom Level：任务要求什么

编码当前明确提出或正在回应的任务成功完成所需认知操作，而非提示词的表面动词。学生纯作答时可沿用可定位前文任务，reason 必须注明来源；“继续”只能在前文有明确尚未完成任务时沿用 Task，不能从智能体名称推断。

Task 可以描述委托 AI 做的高阶任务，但 reason 必须注明 `task_actor=AI`；这不表示学生承担或完成该任务。泛泛“创新一下”没有对象、约束和产物，不能仅凭“创新”赋 L6。

### Student Evidence Level：学生展示什么

只编码学生新增的可见操作及其证据位置。提问也可能包含证据，例如学生先指出两个假设冲突再发问；裸请求“解释一下”本身不是 L2 理解证据。Task 与 Student 必须分别判断，可以不同，也允许一个可判、另一个不可判。

L1–L6 为认知类别，不假定等距，不在本手册直接转换分数。认知复杂性与结论正确性分列：清晰但算错的程序操作仍可判 L3，并标 correctness=incorrect；只有错误答案、看不见操作时不得补想推理过程。高等级不是质量奖励。

### 允许值

| 字段 | 允许值 | 含义 |
|---|---|---|
| task_bloom | L1–L6 / NOT_APPLICABLE / UNDETERMINED | 无教育认知任务用前者状态；任务存在但不足判断用后者 |
| student_evidence_bloom | L1–L6 / NO_EVIDENCE / NOT_APPLICABLE / UNDETERMINED | 分别为可见证据、明确未展示、非学生、不足判断 |

NO_EVIDENCE 与 UNDETERMINED 必须区分：完整看到“继续”而无新增内容是 NO_EVIDENCE；看不到正文或关键前文是 UNDETERMINED。空值只表示尚未标注，不可当上述任一状态。

## 四、L1–L6 操作规则

以下必要证据主要针对 Student 轴；Task 轴判断完成任务是否要求对应操作。示例均为人工构造，假设没有可见复制来源；如来源改变，Student 判定必须相应改变。

### L1 记忆

- **操作定义**：识别、提取或再现已知术语、事实、公式，不展示关系解释。
- **必要证据**：有明确提取目标，学生给出可辨认的事实/名称/公式；Task 的典型要求是列出或识别。
- **不充分证据**：孤立关键词、逐字复制 AI 公式、“知道了”。
- **正例**：前问“均值公式是什么？”学生答“各数之和除以个数。”Task=L1，Student=L1。
- **反例**：“均值”无前文，不能确认是答案还是主题，Student=UNDETERMINED。
- **最易混淆**：L2；复述术语不等于解释意义。
- **边界规则**：短答案不是自动无效；有清晰识别任务时一个词也可为 L1。错答需标错误，不能解释为掌握；若未显示识别行为则不可判。

### L2 理解

- **操作定义**：用自己的表述解释含义、概括关系、分类或举出与概念对应的例子。
- **必要证据**：可见的意义转换或概念—例子连接，而非仅同义替换；Task 要求解释或说明意义。
- **不充分证据**：“我理解了”、原文换词、只要求 AI 解释。
- **正例**：“平均数会被极端值拉动，例如 1、2、100 的平均值不能代表多数值的位置。”Student=L2。
- **反例**：“帮我解释平均数为什么受极端值影响。”Task=L2，Student=NO_EVIDENCE。
- **最易混淆**：L1、L4。
- **边界规则**：一般概念解释为 L2；对具体系统拆解组成及其关系才考虑 L4。不得因出现“因为”自动升级。

### L3 应用

- **操作定义**：在具体对象上执行已知规则、算法或程序。
- **必要证据**：输入与规则、步骤或具体运算之间有可见连接；Task 要求使用已给/已知方法求解。
- **不充分证据**：“用回归吧”、仅报结果且无足够语境、复制代码、请求 AI 计算。
- **正例**：“按给定公式 z=(x−10)/2，x=14，所以 z=2。”Task=L3，Student=L3。
- **反例**：“按这个公式替我计算。”Task=L3，Student=NO_EVIDENCE。
- **最易混淆**：L2、L4。
- **边界规则**：复杂算式不自动成为分析；任务明确且简短答案足以显示唯一规则操作时可考虑 L3，否则需过程补充，不能脑补。程序算错不自动降级。

### L4 分析

- **操作定义**：拆分具体问题，辨识组成、假设、关系或矛盾，说明这些关系对问题的作用。
- **必要证据**：具体对象的至少一个实质关系、分解依据或冲突及其解释；不是只罗列名词。
- **不充分证据**：“深入分析”、无依据分点、只给最终偏好。
- **正例**：“总误差含抽样误差和标注误差；增加学生样本不能消除系统性误标，所以应分开检查。”Student=L4。
- **反例**：“请分析误差。”若对象和预期操作不足则 Task=UNDETERMINED，Student=NO_EVIDENCE。
- **最易混淆**：L2、L5。
- **边界规则**：揭示关系而未按标准作判断，为 L4；按明确标准形成有证据判断才考虑 L5。质疑句可包含 L4，不要求陈述句形式。

### L5 评价

- **操作定义**：依据明确或可定位的标准，使用证据判断方案、论证或结果是否适切、可信或满足要求。
- **必要证据**：评价对象、标准、相关证据与判断之间的连接。标准可在前文给出，但学生必须实施判断。
- **不充分证据**：“不对”“更好”“验证一下”、点赞、没有理由的选择。
- **正例**：“约束要求概率和为 1，你给的 0.7 与 0.6 合计 1.3，因此该结果不满足约束。”Student=L5。
- **反例**：“请检查概率是否合理。”若前文概率对象与标准明确，Task=L5；Student=NO_EVIDENCE。
- **最易混淆**：L4、L3。
- **边界规则**：单纯按公式重算是 L3；指出结构冲突可为 L4；把检验结果与标准相连并形成判断才为 L5。判断错误单独标，不将认知活动与正确性混为一谈。

### L6 创造

- **操作定义**：为具体问题组织出新的、连贯且可执行的方案、模型或产物结构；“新”仅相对于当前任务和已提供内容，不宣称学术原创。
- **必要证据**：明确目标/约束，以及学生提出的组成、组合关系和可实施说明；必须能指出超出可见已有方案的实质贡献。
- **不充分证据**：“创新模型”、模型改名、换参数、工具名堆叠、照搬 AI 的完整方案。
- **正例**：前文未给方案，学生提出：“为在有限复核预算下兼顾覆盖与难例，我设计两路抽样：一部分随机覆盖工具组，另一部分抽分歧记录；保存各自入样概率以恢复总体估计，并预留独立审计集检验遗漏。”Student=L6（本地设计证据，非证明方法有效）。
- **反例**：“把线性回归改名为超级创新模型。”不构成创造；无其他操作时 Student=NO_EVIDENCE。
- **最易混淆**：L3、L5。
- **边界规则**：执行现成组合为 L3；比较并选出最佳现成方案通常为 L5；提出有实质结构变化的可执行组合才考虑 L6。若不知道是否来自 AI，Student=UNDETERMINED；方案有效性另行记录。

## 五、特殊情况决策表

| 情况 | Task 处理 | Student 处理与复核 |
|---|---|---|
| 只有一个关键词 | 有明确前问按任务判；否则 UNDETERMINED | 明确事实回答可 L1；孤立词 UNDETERMINED，不按词典映射 |
| 纯粘贴 | 可判题目要求 | 已知无新增为 NO_EVIDENCE；来源不清为 UNDETERMINED |
| 请求 AI 直接给答案 | 按实际题目及要求判，注明 actor=AI | 无本人操作则 NO_EVIDENCE，不默认 L1 |
| “帮我创新一个模型” | 无对象/约束为 UNDETERMINED；具体设计任务可 L6 | 裸请求 NO_EVIDENCE |
| AI 已给方案，学生说“继续” | 仅在未完成任务明确时沿用；否则 UNDETERMINED | NO_EVIDENCE，不继承 AI 级别 |
| 学生质疑 AI | 按明确待解决任务判 | “你错了”无理由为 NO_EVIDENCE；指出关系/假设冲突可 L4；依据标准作判断可 L5 |
| 学生修正 AI | 按当前任务判 | 规则重算可 L3，结构诊断可 L4，标准检验可 L5；不是一律高阶 |
| 学生要求验证结果 | 例行重算可 L3，按标准评价可 L5；语境不足不可判 | 单纯请求为 NO_EVIDENCE；自己的验证过程另判 |
| 探知侠逐级提示 | 每轮按实际任务判，记录提示来源 | 学生实际证据独立编码；不复制系统预设六级 |
| 逆行侠从目标回溯 | 按当前任务判，可从高到低 | 不将下降解释为退步，不将初始创造目标算学生 L6 |
| 链接无正文 | UNDETERMINED | Student 角色时 UNDETERMINED；不以 URL/文件名猜内容 |
| 无法判断 | 相应轴 UNDETERMINED | 标 low、具体缺失、needs_second_review=true |
| 重复问题 | 保留原任务类别并标重复 | 重复裸请求仍 NO_EVIDENCE；重复本人推理可保留原类别但标重复，不视为新的成长证据 |

## 六、置信度与拒绝确定标签

confidence 表示编码决定的可信程度，不是学生能力、答案正确率或模型预测概率。Task 与 Student 应分别在 reason 记录置信度；表中 confidence 取两轴及角色/来源决定中最低者。NO_EVIDENCE 或 NOT_APPLICABLE 可以是 high。

- **high**：角色与相关来源可判；任务/证据位置完整；符合某级必要条件或明确非等级状态；没有会改变结论的竞争解释。
- **medium**：核心证据成立；相邻类别存在轻微边界疑问，但可依据本手册排除替代解释，且理由可定位。可给暂定级别，但必须二次复核；不得用“多数感觉”代替必要证据。
- **low**：缺关键语境、角色/来源冲突、无法判断学生贡献，或两个以上等级无法依规则排除。受影响轴必须 UNDETERMINED，候选等级只写 reason，例如 `candidates=L4|L5`；另一轴如证据充分可保留确定值。needs_second_review 必须 true。

不得把 low 转为最小候选、最大候选、随机标签或 L1。二次复核仍无足够证据时维持 UNDETERMINED。概率标签需后续校验数据支持，本手册不以主观置信度生成概率。

## 七、Pilot 人工复核表与流程

### 1. 核心 CSV 字段

配套 CSV 是 UTF-8 BOM、仅表头的空白模板，不混入演示数据。每位标注者保存独立副本。

| 字段 | 规则 |
|---|---|
| record_id | 非空唯一派生 ID；可追溯原记录；分段使用后缀 |
| speaker_role | Student / AI / System / Unknown |
| task_bloom | L1–L6 / NOT_APPLICABLE / UNDETERMINED |
| student_evidence_bloom | L1–L6 / NO_EVIDENCE / NOT_APPLICABLE / UNDETERMINED |
| confidence | high / medium / low |
| reason | 必填：Task 来源/执行者、Student 原文证据位置、来源判断、适用规则；无证据则说明缺什么 |
| ambiguity_type | none 或以下代码，多项用分号分隔 |
| needs_second_review | true / false；medium、low、Unknown、未解决来源问题均为 true |

ambiguity_type 代码：role_boundary、source_attribution、context_missing、task_unspecified、level_boundary、multi_operation、prompt_induced、copy_suspected、duplicate、link_only、correctness_uncertain、other。none 不与其他代码并存；other 必须解释。

推荐 reason 格式：`Task: L5, source=r12, actor=Student, conf=high; Evidence: “合计1.3，不满足和为1”, span=...; source=student_added; rule=L5; evidence_conf=high; correctness=correct`。不要求暴露真实身份。

最小 CSV 只保留上述八列；执行窗口应另建映射/审计表保存：原始文件/行/文本位置、student_id、session_id、parent_turn_id、context_record_ids、annotator_id、manual_version、annotation_round、内容来源、task_actor、两轴置信度、correctness、duplicate_group_id、智能体/提示信息、裁决与变更历史。原文和私密标识留在受控原始数据中，不复制到公开交付物。

### 2. 建议 pilot 流程

1. 主执行窗口在只读副本上建立记录映射和必要上下文包，先试用本手册人工案例校准规则。
2. pilot 样本兼顾学期、智能体、长度、任务类型及来源/链接/重复疑难；另保留随机审计样本。记录入样方式，疑难过抽样结果不能直接代表总体比例。本版不冻结样本量。
3. 两位标注者对相同文本独立判断，第一轮不看自动标签、另一人结果、学生总分或排行榜。必要的提示文本必须保留，能遮蔽的品牌名称/预设层级标签予以遮蔽，避免路径名称诱导。
4. 先定角色/来源，再定两轴，最后记置信度和歧义。不能先看 Task 后自动填同级 Student。
5. 对所有 medium/low 及两人分歧进行裁决；同时随机复核部分 high，避免只检查困难样本。保留原始双标，不能用裁决标签计算初始一致性。
6. 分别报告角色、来源、Task、Student 的一致性、可判率与拒判原因。L1–L6 的有序一致性只在双方均可判的子样本计算，同时披露该分母和全部状态交叉表，不能靠删掉疑难样本美化一致性。
7. 六级为主编码。若探索三阶，暂用 L1–L2 / L3–L4 / L5–L6，明确这是项目候选折叠，非文献证明的唯一划分；报告合并损失，不为提高一致性而事后挑分组。
8. pilot 结束形成 V0.2 修订清单。若规则变动影响既有判定，记录影响范围并重标相关 pilot 条目；不静默覆盖，也不扩展至主模型。

## 九、当前最难判的五类案例

1. **AI 文本的实质重组与表面改写**：需要比较可见前文、逐段标明学生新增解释；缺前文不能判归属。
2. **有理由的质疑、诊断与评价**：L4 关系分析和 L5 标准判断可能交织，需要明确标准是否真实参与判断。
3. **短答案或单词回复**：同一词在不同前文中可为 L1、任务请求或不可判，不能以长度设统一阈值。
4. **提示强引导下的高阶回答**：提示可能已经提供推理骨架，需要分离学生填充事实、执行步骤与新增结构，不能以有提示为由全部排除，也不能全额归学生。
5. **模型组合、改进与创造**：组合工具名不等于 L6；需判结构贡献相对既有方案是否实质新增，且不把有效性或学术新颖性混入等级。

## 十、必须由真实 pilot 决定的规则

下列事项目前只是候选，不能在无数据下宣称成立：

- 原始字段能否稳定分离角色、复制来源与上下文；source_unknown 的实际频率及复核可恢复程度。
- 无 session ID 时的合理边界、任务切换识别方式；是否有证据支持时间阈值。
- 复合 Turn 的分段粒度；最高可支持操作是否掩盖混合表现，以及两名标注者是否能一致定位证据。
- L2/L4、L3/L5、L5/L6 边界的真实混淆模式；是否需补充学科专属例子而不改变构念。
- “学生实质新增”的可操作判据，尤其重组 AI 文本、填空式脚手架与组合模型；不预设相似度阈值直接裁决。
- high/medium/low 是否与复核分歧相符；不能预设数字概率或仅依赖自动模型自报置信度。
- 六级与候选三阶在一致性、拒判率、信息损失上的实际取舍；不得只追求更高一致性。
- pilot 样本量、疑难/随机样本比例、稀有类别支持量、复核成本和停止标准；需根据初轮覆盖和分歧制定，不凭单一一致性阈值验收。
- 重复/近重复的识别与上下文依赖，以及何种新增内容值得独立保留；本阶段只标记，不更改真实数据计数。

不随 pilot 便利性放宽的约束：双轴独立、AI 内容不自动归学生、low 拒绝确定标签、未知不填 L1、保留初始双标与裁决轨迹、日志不直接代表长期能力。pilot 可改进可执行性，不能验证缺失的独立学习结果或因果效应。
