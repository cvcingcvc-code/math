# DESIGN

## 画布与母版
- 画布 1280×720，安全边距左右 40px。
- 内容页页眉 y=0–80，标题区 y=48–128，内容区 y=140–650，页脚 y=660–700。
- 背景只用 `#FFFFFF` / `#F7F9FC`。
- 主色 `#1E4FA8`，深蓝 `#0E3F8C`，浅蓝 `#E8EFF8`，中蓝 `#3D7BD9`，红 `#D9534F`，文本 `#1A2230` / `#4A5568`，线 `#D6DCE5`。
- 字体仅用 Arial 与 Microsoft YaHei；正文 22–26px，标题 32–40px，页脚 14–16px。

## 视觉语言
- 学术答辩风：证据图、流程图、数据锚点优先。
- L1 视觉全部来自冻结 F1–F6；不新增数据图，不重绘数字。
- 红色只标示 `NOT_SUPPORTED`、`NOT_RUN`、`ABSTAIN`、`NO_EFFECTIVE_EVIDENCE` 等限制或负结果。
- 每页至少一个大视觉锚点：冻结图、巨大数字或完整链路。
- 内容页尽量填充内容区，避免空白海报化。
