证据感知评价框架

Evidence-Aware Evaluation Framework ｜ 把「表现水平」与「证据支持」分开

观察到的结果 ≠ 可靠证据（Observed Result ≠ Reliable Evidence）。 当证据缺失、冲突或低可信时，原始信号（Raw Signal）不应被直接当作可靠结论——模型把「表现有多高」和「这条表现有多少可审查支撑」拆成两个量。

1

研究问题 Research Question

AI 辅助学习里，学生的答案、操作和行为并不都同样可信：有的记录信息完整、学生独立完成；有的带有明显 AI 引导、上下文截断或来源冲突。看见一个高分，不等于这条分数有同样高的证据支持。

研究问题：给定可观察的学生证据记录，如何显式地把 表现水平 与 证据支持度 分开，从而在证据不足时拒绝装作确定？

核心发现 Core Finding

分数稳定 ≠ 证据支撑稳定（Score Stability ≠ Evidence Support Stability）。 归一化分数保持不变，而有效证据支持显著下降 —— 分数稳定，不等于支撑它的证据同样稳定。

3.5625 / 0.375 / 1.125

有效支持 Effective Support（Σw）
16 → 12 → 6 → 6
M0 → M1 → M2 → M3，证据支撑下降。

视觉重点：Score 稳定 ≠ Evidence Support 稳定。 四个模型的归一化分数完全相同（3.5625），但有效支持从 16 降到 6、覆盖率从 0.228571 降到 0.085714。prompt 模块承担主要支持下降（M1→M2）；context 模块在当前可判读记录中无变异（M2=M3，不可识别独立效应）。

数据构成（N=70）：16 条可判读（L2×5、L3×5、L4×1、L5×2、L6×3）+ 19 条 NO_EVIDENCE + 35 条 UNDETERMINED = 54 条 NO_EFFECTIVE_EVIDENCE。16 条可判读共享 prompt=true / context=false / confidence=medium，各加权方案施加同一常数因子，归一化后抵消 —— 因此 Raw 与 Adjusted 相同，不得写成 improvement。

五条验证路径 Five Validation Paths

每条路径只给 问题 Question / 关键结果 Key Result / 含义 Meaning / 证据边界 Limit，不铺长文。

1 · 基线对比 Baseline
问题 Question：可靠性层是否必要？
关键结果 Key Result：四模型 ABL 均 3.5625；Raw-only support=16，主模型=6。
含义 Meaning：可靠性层带来 Raw-only 没有的 graded support。
证据边界 Limit：不证明乘法形式必需；不证明精度/预测优越。
2 · 组件消融 Ablation
问题 Question：组件是否只是装饰？
关键结果 Key Result：有效权重 16→12→6→6，分数恒 3.5625。
含义 Meaning：confidence / prompt 组件确实改变 support accounting。
证据边界 Limit：模块差异 ≠ 独立因果效应；context 无变异不可识别。
3 · 敏感性与稳健性 Sensitivity / Robustness
问题 Question：现象是否只是单一参数点产生？
关键结果 Key Result：±10%/±20% → 0 个 decision-state flips；693 网格 660 defined / 33 undefined。
含义 Meaning：局部结构稳定性；学生 ranking 为 NOT_APPLICABLE。
证据边界 Limit：不是统计置信区间，也不是全局稳健性。
4 · 反例与失败分析 Failure Case
问题 Question：高 Raw 是否仍被接受？
关键结果 Key Result：P108 L6 → R=0.375 → LOW_SUPPORT；P072/P035 返回 NO_EFFECTIVE_EVIDENCE。
含义 Meaning：High Raw ≠ High Evidence Support；Missing Evidence ≠ Score 0。
证据边界 Limit：不是准确率/真实错误率；无 true outcome。
5 · 外部迁移 External Transfer
问题 Question：是否只为教育数据硬写？
关键结果 Key Result：BTC n=1698：Gate1/Gate2 SUPPORTED，Gate3 NOT SUPPORTED。
含义 Meaning：结构可迁移（structural portability）。
证据边界 Limit：非教育泛化/交易优势；不能成为第二主线。
