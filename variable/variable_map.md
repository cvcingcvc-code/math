# S3 变量字典与数据来源映射

> 状态：FACT=附件/赛题中直接可核信息；ASSUMPTION=暂定操作定义；UNKNOWN=字段未核实或不可观测；DECISION=本阶段约定。所有衍生变量在标签/队列核验前均为候选，不能解释为长期能力。

## Turn-level

| 变量 | 定义 | 来源字段/构造 | 是否直接观测 | 缺失风险 | 解释边界 |
|---|---|---|---|---|---|
| `student_text` | Turn 中可归属学生的原始文本，保留原文、分句与来源索引。 | `问答记录` 或讨论导出中的 `Q/A` 对话文字；按显式角色和轮次解析。 | 部分直接；混合问答需解析。 | URL-only、空白、格式异常、语音转写缺失、学生文字与 AI 改写混合。 | 仅可见表达，不代表完整思维过程；AI 文本不得混入。 |
| `ai_text` | Turn 中智能体生成的原始回答/追问。 | 对话记录中 `A:`/AI 角色文本；以平台事件结构优先。 | 部分直接。 | 多轮合并、边界不清、AI 回答存为外链、缺失。 | 用于 task/path/scaffold 识别，不作为学生学习表现计分。 |
| `agent_type` | 本轮关联智能体的规范类别，如探知侠、逆行侠、数模匹配等。 | 秋季 `智能体类型`/使用次数表列；其他表的对话模板、来源、参与讨论表。 | 秋季部分直接；春季问答大表仅有 `问答来源`，不等价具体 agent。 | 同一来源含多智能体、版本更新、agent 字段缺失、课程外日志。 | 未经核实的 agent 标为 Unknown；`问答来源=AI智能体`不能映射具体工具。 |
| `task_bloom` | 当前问题/AI 指令要求的认知活动层级 L1–L6，另设 U=信息不足。 | 学生问题、AI 追问、课程任务说明；人工 codebook 标注，保留任务上下文来源。 | 否，须标注。 | 任务上下文缺失、多个嵌套任务、仅有回答无提示。 | 反映任务要求，不是学生展示层级或能力。 |
| `student_evidence_bloom` | 学生文本实际可见的认知证据层级 L1–L6；U=无足够可判读证据。 | 仅 `student_text`，由人工标注并抽样审查。 | 否，须标注。 | 学生话语过短、答案复制/改写归属不清、AI 对话缺失。 | 反映交互中可观察表现证据，不等价稳定能力/学习增量。 |
| `label_probability` | 对该 turn 真实标签类别的概率向量 (p_{ik}, k=1...6)，总和为 1；U 作为不可判读状态单独处理，不强行变成 L1。 | 人工双标/裁决与分层抽样校验集；按 agent、semester、置信度层校准 AI 预标签混淆。 | 否，衍生候选。 | 稀有类别校验量不足、抽样权重错误、校准层小样本。 | 是分类不确定性，不是学生“能力概率”；应保留原预测和抽样层。 |
| `speaker_confidence` | 当前 turn 属于 Student/AI/System/Unknown 的识别置信度，0–1 或预设高/中/低。 | 明确平台角色标记/问答格式及人工核验；规则来源需留字段。 | 多数未直接观测，部分由格式确定。 | 文本混合、粘贴、引用、转录异常。 | 是来源识别可信度；不能和 Bloom 标签置信度合并成一个数。 |
| `timestamp` | Turn 创建/发送时间，统一时区后保存。 | `问题建立时间` 或话题发布时间。 | 部分直接。 | 缺失、导出时区差异、按问题而非对话更新时间、日期错入其他学期。 | 只支持时间排序/窗口过滤；时间先后本身不表示学习变化。 |

## Session-level

| 变量 | 定义 | 来源字段/构造 | 是否直接观测 | 缺失风险 | 解释边界 |
|---|---|---|---|---|---|
| `trajectory` | 按时间排序的学生可观察证据层级序列 ((z_1,...,z_J))，可并列记录 task 序列和 student evidence 序列。 | Turn labels + timestamp + session boundary。 | 否，衍生。 | session ID 缺失、次序/时间不准、标签 U、对话行不可拆。 | 轨迹是记录到的交互路径，不是认知发展轨迹。 |
| `session_length` | 会话中有效学生证据 turns 数；另保留总 turns、AI turns、持续时间，避免单一长度混义。 | 解析后的角色序列和时间戳。 | 部分可构造。 | 边界不可见、同一人跨 session 合并、AI 回答缺失。 | 长度可能由工具结构/导出规则决定，不应直接解释为投入度。 |
| `CTQ` | 候选认知跃迁质量/方向摘要，基于相邻有效学生证据层级变化；见 research_spec/S3 指标部分。 | `student_evidence_bloom` 序列。 | 否，衍生。 | 有效 transition 少、主体归属不明、路径被 AI 预设。 | 仅表达观察序列方向和一致性；不等于能力提高；必须与 task path 并列。 |
| `agent_path` | 会话中实际出现的 agent 序列及其引导方向/脚手架编码，例如逐级上行、创造目标倒推、开放式答疑。 | `agent_type`、AI prompt text、课程智能体说明文档；人工路径 codebook。 | 部分可观察，路径类别待编码。 | 智能体文本未留存、版本变更、tool type 不全。 | agent 名称不自动等于实际引导路径；模板规则需核验。 |
| `interaction_depth` | 可重复定义的互动深度特征向量，候选含学生证据 turns、往返轮数、学生追问/解释/修订/核查次数。 | 解析的 student/AI turns；不能只用问答总行数。 | 否，衍生。 | 对话被压成单行、事件断裂、AI 未记录。 | 频次/深度是过程强度；不天然为正向价值。 |

## Student-level

学生级变量按同一 cohort 口径、合格文本和已验证 turns 聚合。没有 eligible turn 的学生指标应为 NA/未观察，而非 0； coverage 独立报告。

| 变量 | 定义 | 来源字段/构造 | 是否直接观测 | 缺失风险 | 解释边界 |
|---|---|---|---|---|---|
| `ABL` | 有效学生证据标签的平均 Bloom 层级：(sum_k kN_k/sum_kN_k)；概率版以 (p_{ik}) 求期望。 | Student turns 的 `student_evidence_bloom`/`label_probability`。 | 否，衍生。 | 标签 U、文本不全、话语主体错误。 | 反映可见文本层级均值，易受话语数/提示影响。 |
| `HOT` / `HOT%` | 学生证据属于 L4–L6 的占比；记 0–1 比例，展示时可乘 100%。 | 同 ABL。 | 否，衍生。 | 同 ABL；高阶类别少时方差大。 | 不是高阶能力率；重复/提示诱导可抬升。 |
| `CTQ` | 汇总 session CTQ；主候选为有效 session 等权平均，同时报告有效 transition 数和区间。 | Session `CTQ`。 | 否，衍生。 | 会话不可识别、短序列、session 构造依赖规则。 | 测路径方向性，不等于学习因果效应。 |
| `DHI` | 层级分布健康度：候选以学生实际层级分布 (p) 与明确论证的目标分布 (p^*) 距离计算。 | 学生 L1–L6/L/M/H 计数 + 教育目标 (p^*)。 | 否，衍生；目标分布未知。 | 样本稀疏使分布不稳；p* 无来源。 | 对“理想分布”的价值判断高度敏感，不可先用全体样本均值冒充教育理想。 |
| `MAB` | 多智能体广度：至少有一次有效学生互动的不同、核实 agent type 数，之后按可用类型上限饱和。 | agent usage table / agent type mapping / valid interaction turns。 | 秋季使用次数表可部分观测；春季 agent mapping 不足。 | 使用次数表与文本样本不一致；虚增类型；季节 agent universe 不同。 | 广度不是效果；跨 cohort 需共同 agent 集合或分别报告。 |
| `feedback` | 学生显式反馈/自评/赞踩/课程讨论意见，保留量表与文本含义。 | 秋季评价/调优列、课程反馈讨论；春季参与和话题反馈文件。 | 部分直接，但字段差异大。 | 不回应者、赞踩稀疏、反馈偏向强体验者。 | 感知和满意度独立于客观学习表现；不直接并入 AIV baseline。 |
| `AIV` | 基于经确认且可比的学生表现/过程维度形成的透明非负权重候选合成得分。 | ABL/HOT/CTQ/DHI/MAB 等，具体候选见下方；本阶段不冻结最终公式。 | 否，衍生。 | 任一组件不可用、域间不等值、权重不稳。 | 形成性摘要，不是因果效应或个人长期能力真值。 |
| `AIV_uncertainty` | 标签、抽样、学生/AI归属、缺失和权重不确定性传播到 AIV 后的区间/分布。 | label_probability + bootstrap + 候选权重范围/模型。 | 否，衍生。 | 上游不确定性没有校准、缺失机制不知。 | 量化现有建模不确定性，不包括所有未观测偏差。 |
| `rank_stability` | 在可接受的标签/样本/权重方案下，学生排序/前 k 集合保持稳定的概率或统计量。 | 多次 AIV 计算的 ranks；仅作诊断。 | 否，衍生。 | 学生覆盖低、模型空间任意、样本太小。 | 排名稳定不等于排名有效，也不授权高风险使用。 |

## Cohort-level

| 变量 | 定义 | 来源字段/构造 | 是否直接观测 | 缺失风险 | 解释边界 |
|---|---|---|---|---|---|
| `semester` | 官方学期归属。 | 表名/名单/课程官方日期；禁止只凭数据导出日推断。 | 文件标签部分直接；单行归属需筛选。 | 大表跨 2024–2026，多来源混杂。 | 需固定 cohort window。 |
| `class` | 正式班级/班群。 | 学生 roster、话题参与表。 | 部分直接。 | 秋春字段不统一，可能有多班/小组。 | 不是学生固定属性，不能无核实跨表连接。 |
| `course` | 正式课程/教学内容版本。 | 课程附件及教学管理字段。 | 赛题描述可知数学模型课程；行级字段未知。 | 班级、教师、课程资源差异。 | 课程名相同不等于课程难度或测量可比。 |
| `agent_mix` | cohort 中可核实 agent 暴露比例/覆盖集合。 | 智能体使用次数表、agent type 和使用参与数据。 | 秋季部分直接；春季日志仅有混合来源字段。 | 不同来源/版本、来源与 agent 混同、学生名册不齐。 | 暴露分布描述，不等于处理效果。 |
| `sample_coverage` | eligible roster 中有至少一条可用文本/日志者占比，并分开报告各筛选阶段。 | roster 学号分母 + 匹配日志与可判读文本分子。 | roster 部分可用；秋季全体 roster 未核实。 | 名单并集定义不明；无法匹配/缺记录。 | “未观察到记录”不得解释为未使用或零能力。 |

## 候选核心派生变量统一约定

- 可评分等级编码：L1=1,…,L6=6；U（无证据/不可判读）不作为 L1 或零分。`p_{ik}` 只针对有效六类概率，且 (sum_{k=1}^6 p_{ik}=1)。
- Turn 数、session 数、AI 使用次数分别报告；不同分母不可互换。学生级指标要附有效学生 turn/session/transition 数。
- `feedback` 与 AI 回答质量不纳入 AIV baseline 候选，除非后续能证明它们测量目标构念且不与客观结果混淆。
- 概率标签、CTQ 和 AIV 的公式是候选规格，权重、理想分布、最低有效样本量均待人工决策/数据诊断。
